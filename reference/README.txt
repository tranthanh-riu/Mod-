Thư mục chứa các file .jar / modpack tham khảo (không đóng gói vào mod):
- Chép file .jar của Elden Ring Weapons Pack (1.19.2) vào đây để trích xuất model/texture và port lên 1.20.1.
- Chép file .jar của Elden Ring Nightreign Gear (1.20.1) hoặc manifest.json của EldenCraft vào đây để phân tích xung đột và cân bằng chỉ số.
